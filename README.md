# RiksKollen Backend

En enkel proxy-server som hämtar data från riksdagens öppna API.

## Deploy på Railway

1. Gå till railway.app och skapa ett gratis konto
2. Klicka "New Project" → "Deploy from GitHub repo"
3. Ladda upp denna mapp
4. Railway startar servern automatiskt

## Lokalt
```bash
npm install
npm start
```
